# Speech Emotion Recognition (SER)

A production-quality Speech Emotion Recognition system using transfer learning with Wav2Vec2 / HuBERT.

Classifies speech audio into 4 emotions: **angry**, **happy**, **neutral**, **sad**.

## Datasets Used

| Dataset | Speakers | Emotions | Files | Notes |
|---------|----------|----------|-------|-------|
| **CREMA-D** | 91 (48M, 43F) | 6 | ~7,442 | Multimodal, emotion levels (lo/md/hi) |
| **RAVDESS** | 24 (12M, 12F) | 8 | 1,440 (speech) | Audio-only speech selected |
| **SAVEE** | 4 (all male) | 7 | 480 | British English |
| **TESS** | 2 (all female) | 7 | 2,800 | Young + Old adult female |

### Target Emotions

Only 4 emotions are used from each dataset:

| Target | CREMA-D | RAVDESS | SAVEE | TESS |
|--------|---------|---------|-------|------|
| angry | ANG | 05 (Angry) | a | angry |
| happy | HAP | 03 (Happy) | h | happy |
| neutral | NEU | 01 (Neutral) | n | neutral |
| sad | SAD | 04 (Sad) | sa | sad |

All other emotions (fear, disgust, surprise, calm, pleasant_surprise) are discarded.

## Setup

### 1. Install Dependencies

```bash
cd ser/
pip install -r requirements.txt
```

### 2. Download Datasets

Download from Kaggle:
- [CREMA-D](https://www.kaggle.com/datasets/ftaham/multi-source-emotion-dataset)
- [RAVDESS](https://www.kaggle.com/datasets/orvile/ravdess-dataset)
- [SAVEE](https://www.kaggle.com/datasets/ejlok1/surrey-audiovisual-expressed-emotion-savee)
- [TESS](https://www.kaggle.com/datasets/ejlok1/toronto-emotional-speech-set-tess)

### 3. Place Datasets

Put the raw datasets in `datasets/raw/`:
```
datasets/raw/CREMAD/   (contains AudioWAV/ folder)
datasets/raw/RAVDESS/  (contains Actor_01/ ... Actor_24/ folders)
datasets/raw/SAVEE/    (contains ALL/ folder)
datasets/raw/TESS/     (contains emotion subfolders)
```

## Usage

### Step 1: Organize Dataset

Scans raw datasets, extracts target emotions, renames files, generates metadata.

```bash
python organize_dataset.py
```

Output:
- `datasets/merged/` with files organized by emotion
- `metadata.csv` with full file manifest

### Step 2: Split Dataset

Performs stratified 70/15/15 train/validation/test split.

```bash
python split_dataset.py
```

### Step 3: Check Distribution (Optional)

Visualize class balance.

```bash
python check_distribution.py
```

Output:
- Console statistics
- `outputs/distribution_bar.png`
- `outputs/distribution_pie.png`

### Step 4: Preprocess Audio (Optional)

Normalize, trim silence, ensure consistent format.

```bash
python preprocess_audio.py
```

### Step 5: Train

**Phase 1** — Train classifier head only (backbone frozen):

```bash
python train.py --phase 1
```

**Phase 2** — Fine-tune entire model (backbone unfrozen):

```bash
python train.py --phase 2 --epochs 10
```

Output:
- `outputs/best_model_phase1.pt` (or phase2)
- `outputs/final_model_phase1.pt`

### Step 6: Evaluate

```bash
python evaluate.py
python evaluate.py --model outputs/best_model_phase2.pt
```

Output:
- Classification report (precision, recall, F1)
- `outputs/confusion_matrix.png`

### Step 7: Predict

Single file:
```bash
python predict.py path/to/audio.wav
```

Batch mode:
```bash
python predict.py --batch path/to/folder/
```

## Model Architecture

```
Input: Raw waveform (16kHz, mono)
    │
    ▼
Wav2Vec2-base (frozen in Phase 1)
    │
    ▼
Mean pooling over time dimension
    │
    ▼
Linear(768 → 256) → ReLU → Dropout(0.3)
    │
    ▼
Linear(256 → 4)
    │
    ▼
Output: 4 emotion logits
```

### Why Wav2Vec2?

- Pretrained on 960h of LibriSpeech — strong speech representations
- 768-dim transformer features capture prosody, pitch, rhythm
- Well-supported in Hugging Face Transformers
- Proven SER benchmark performance
- HuBERT-base is a drop-in alternative with comparable results

### Transfer Learning Strategy

Same approach as EfficientNet transfer learning:

1. **Phase 1**: Freeze backbone, train classifier only (fast convergence)
2. **Phase 2**: Unfreeze backbone, fine-tune with lower LR (refine features)

## Configuration

All tunable parameters are in `config.py`:

- **Paths**: Dataset locations, output directories
- **Emotions**: Target emotions, label mappings, per-dataset emotion codes
- **Audio**: Sample rate (16kHz), normalization, silence trimming, duration bounds
- **Model**: Backbone name, classifier size, dropout
- **Training**: Batch size, learning rates, epochs, early stopping, weight decay
